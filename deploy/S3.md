# S3 trong Petie

Backend tự dùng S3 khi AWS_S3_BUCKET_NAME có giá trị. Nếu để trống sẽ tiếp tục lưu ảnh vào uploads/ như trước. Ảnh cũ trên EC2 chưa được di chuyển tự động.

Các biến backend cần có:

```env
AWS_REGION=ap-southeast-1
AWS_S3_BUCKET_NAME=ten-bucket-thuc-te
PUBLIC_URL=http://13.212.26.2
```

AWS SDK đọc AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY và AWS_SESSION_TOKEN (nếu có) từ môi trường. Khi gắn IAM Role cho EC2, có thể bỏ các access key khỏi .env để dùng quyền của instance. Không đưa access key vào Flutter hay Git.

Kiểm tra kết nối tại backend/:

```bash
npm run s3:check
```

Kiểm tra đầy đủ ghi, đọc, xóa một object tạm:

```bash
npm run build
node dist/scripts/check-s3.js --write
```

Quyền IAM cần cho ứng dụng: s3:PutObject và s3:GetObject trên uploads/* của bucket. Lệnh check dùng thêm s3:ListBucket (HeadBucket) và s3:DeleteObject để xóa object kiểm tra. Backend không tự tạo bucket hoặc đổi bucket policy.

POST /api/v1/media vẫn nhận JSON {content: base64, extension: jpeg|jpg|png|webp}; cần JWT. Giữ giới hạn 4 MB, kiểm tra định dạng từ nội dung ảnh và sinh tên UUID. Không cần đổi Flutter.

URL trả về có dạng PUBLIC_URL/api/v1/media/s3/uuid.png. Backend đọc S3 và trả dữ liệu ảnh; bucket vẫn có thể giữ private và không cần CORS của S3 cho Flutter. Đây là ảnh xã hội xem được qua URL không cần đăng nhập; không dùng route này cho hồ sơ y tế riêng tư hoặc tài liệu nhạy cảm. URL ổn định không hết hạn theo presigned URL. Khi tải lớn, có thể chuyển phân phối ảnh sang CloudFront sau này.

Tài liệu AWS: https://docs.aws.amazon.com/sdk-for-javascript/v3/developer-guide/setting-credentials-node.html

Nếu EC2 cấu hình nhỏ, có thể dùng deploy/update-s3-low-memory.sh để giới hạn heap Node khi cài dependencies. Đây là bước cập nhật backend, cần thực hiện sau khi EC2 hoạt động bình thường.


Đã triển khai và kiểm tra EC2: upload có JWT trả 201; đọc ảnh qua Nginx trả 200, bytes và CORS đúng. Đã thêm swap 1 GB trên volume hiện có và bật pm2-ubuntu tự khởi động khi reboot. Trên EC2 nhỏ, cài dependencies với heap 192 MB, build TypeScript dùng heap 512 MB. Object và tài khoản kiểm tra đều đã xóa.
